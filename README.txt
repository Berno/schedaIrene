# Bodybuilding Tracker PWA

## Uso su iPhone
1. Pubblica l'intera cartella su un hosting statico HTTPS.
2. Apri l'URL in Safari.
3. Condividi → Aggiungi alla schermata Home.
4. Usa sempre lo stesso URL per mantenere lo stesso Local Storage.

## File
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

La PWA salva i dati solo nel Local Storage del browser. Fai periodicamente un Backup JSON.
